==========================================
  在服务器上直接执行（复制粘贴）
==========================================

【第一步：进入项目目录】

cd /opt

rm -rf workflow workflow-main

==========================================
【第二步：下载项目 ZIP 文件】

# 尝试方法1（GitHub 直接下载）
wget -O workflow.zip "https://github.com/jinghoor/gongzuoliu123/archive/refs/heads/main.zip"

# 如果失败，尝试方法2（使用代理）
# wget -O workflow.zip "https://ghproxy.com/https://github.com/jinghoor/gongzuoliu123/archive/refs/heads/main.zip"

# 如果还失败，尝试方法3（镜像站）
# wget -O workflow.zip "https://hub.fastgit.xyz/jinghoor/gongzuoliu123/archive/refs/heads/main.zip"

==========================================
【第三步：解压项目】

unzip workflow.zip

mv gongzuoliu123-main workflow

rm workflow.zip

cd /opt/workflow

==========================================
【第四步：创建数据目录和环境变量】

mkdir -p data uploads logs

cat > .env << 'EOF'
PORT=1888
NODE_ENV=production
DOUBAO_API_KEY=09484874-9519-4aa3-9cd4-f84ef0c6d44e
EOF

chmod 600 .env

==========================================
【第五步：启动服务】

docker-compose up -d --build

==========================================
【第六步：验证部署】

docker-compose ps

curl http://localhost:1888/health

==========================================
【如果下载失败，可以手动上传】

如果所有下载方式都失败，可以：
1. 在你的本地电脑上打包项目
2. 使用 scp 上传到服务器
3. 在服务器上解压
