========================================
  快速部署命令（复制使用）
========================================

【步骤 1】连接服务器
ssh -p 64478 root@206.119.175.36

【步骤 2】执行部署（复制整段命令）
cd /root/baodangongzuoliu && git fetch origin main && git reset --hard origin/main && docker compose down && docker compose build --no-cache && docker compose up -d && docker compose ps

========================================
  命令说明
========================================

cd /root/baodangongzuoliu
  → 进入项目目录

git fetch origin main
  → 从 GitHub 获取最新代码

git reset --hard origin/main
  → 重置到最新版本（覆盖本地修改）

docker compose down
  → 停止并删除旧容器

docker compose build --no-cache
  → 构建新镜像（不使用缓存）

docker compose up -d
  → 启动服务（后台运行）

docker compose ps
  → 查看服务状态

========================================
  其他常用命令
========================================

查看日志：
docker compose logs -f

重启服务：
docker compose restart

停止服务：
docker compose down

查看容器状态：
docker compose ps
